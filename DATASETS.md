Dataset Sources and Download Links

This file lists the original source repositories and download links for the three datasets used in FakeLens.


Dataset 1: ArtiFact – Real vs Synthetic Image Dataset
Description: Cross-generator image dataset containing real images and synthetic images generated by 25 distinct methods (GANs, Diffusion, inpainting, and transformers).
Dataset Link: https://github.com/awsaf49/artifact


Dataset 2: DeepFakeFace (DFF) – Multiclass Deepfake Face Dataset
Description: Facial manipulation benchmark featuring authentic facial portraits (CelebA, FFHQ, Wikipedia) and synthetic manipulations (text-to-image, inpainting, and insight face-swap).
Dataset Link: https://huggingface.co/datasets/OpenRL/DeepFakeFace


Dataset 3: CIFAKE – Real and AI-Generated Synthetic Images
Description: Standardized dataset containing 60,000 real CIFAR-10 images and 60,000 synthetic images generated via Stable Diffusion v1.4, compressed to 32x32 pixels.
Dataset Link: https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images


Directory Structure for Local Dataset Placement

If you want to train from scratch using raw image files, download the datasets from the links above and place them into the following directories:

Fake Lens/
├── data/
│   ├── deepfakeface/
│   │   ├── wiki/
│   │   ├── text2img/
│   │   ├── inpainting/
│   │   └── insight/
│   ├── artifact/
│   │   ├── 0_real/
│   │   └── 1_fake/
│   └── cifake/
│       ├── train/
│       └── test/

The corresponding split manifests defining train, validation, and test partitions are already included in datasets/manifests/.
